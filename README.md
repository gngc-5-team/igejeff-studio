# 이게제프 스튜디오 사이트

빌드 과정이 없는 정적 사이트입니다. GitHub Pages에 그대로 올릴 수 있습니다.

2026년 11월 8일부터 첫 화면은 팀이 고른 문종훈 디자인의 게임 로비형 한 화면입니다. 예전 디자인의 게임 목록, 게임 상세, 스튜디오 페이지는 소개자료 PDF 등에 들어간 링크가 깨지지 않도록 그대로 둡니다.

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 화면. 게임 로비처럼 왼쪽 메뉴로 메인, 게임 선택, 작업 방식, 실험 기록, 업적, 퀘스트, 파티를 바꿔 봅니다. 스타일과 스크립트가 이 파일 안에 다 들어 있고, 글꼴은 Google Fonts에서 받습니다. |
| `games.html` | (예전 디자인) 게임 목록. 줄에 마우스를 올리면 오른쪽 미리보기가 바뀝니다. |
| `games/*.html` | (예전 디자인) 게임 상세. 플레이, 조건, 들은 말, 소개, 회고, 만든 방식을 차례로 보여 줍니다. |
| `studio.html` | (예전 디자인) 문제와 방식, 실험 조건표, 기술, 성과, 배운 것, 다음 6개월, 팀. |
| `play/nyangdoseom/` | 냥도일섬 Unity 웹 빌드(약 59MB). `index.html`만 플레이 창에 맞게 고쳤습니다. 새 빌드로 바꿀 때 이 수정을 다시 적용합니다. |
| `styles.css`, `site.js` | 예전 디자인 페이지가 함께 씁니다. 첫 화면은 쓰지 않습니다. |

## 디자인 원칙 (예전 디자인 페이지)

- 한 화면에 메시지 하나, 버튼은 둘까지.
- 제목만 읽어도 이야기가 이어지게 쓴다.
- 색은 게임 화면이 갖고, 사이트는 종이색과 먹색만 쓴다.
- 연출 때문에 내용을 기다리게 하지 않는다. 진입 게이트, 스크롤 탈취, 소리 자동 재생은 쓰지 않는다.

## 로컬에서 보기

```bash
python3 -m http.server 8770
```

## 게임을 추가할 때

1. `games/`의 비슷한 페이지를 복사해 내용을 고칩니다.
2. `games.html`의 목록과 미리보기에 추가하고, 앞뒤 게임 페이지의 이전·다음 링크를 고칩니다.
3. 첫 화면 `index.html`의 실험 기록(`.seg`와 `.slide`)에 번호 순서대로 넣고, 바로 할 수 있는 게임이면 게임 선택(`.gthumb`, `.ginfo`)에도 넣습니다. 타이틀 화면 16:9 이미지는 `assets/img/`에 둡니다.

웹 게임은 itch.io 업로드 번호로 `https://itch.io/embed-upload/<번호>?color=0b0c12`를 `data-play`에 넣으면 사이트 안에서 돌아갑니다.

## 글꼴

Pretendard(SIL OFL 1.1)를 씁니다. `assets/fonts/site.woff2`는 사이트에 쓰인 글자만 담은 약 106KB 파일이라 빠르게 뜹니다. 새 글자가 생기면 `assets/fonts/pretendard/`에서 그 글자가 든 조각만 추가로 받으니 그대로 둬도 깨지지 않습니다.

## 공개 범위

모든 페이지에 `noindex`가 있어 링크로만 들어올 수 있습니다. 팀 동의가 끝나면 지웁니다.
