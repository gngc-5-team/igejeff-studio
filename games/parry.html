소개

적의 공격을 받아쳐 능력을 빼앗고, 빼앗은 능력으로 드론을 강하게 만듭니다. K-푸드 몬스터, 드론 뽑기, 자동 사냥터, 100층 던전, 영어판까지 넣었습니다. Roblox 어린 이용자를 겨냥합니다.

같은 핵심을 Steam 코어 액션 유저에게 시험하는 게임이 디버그 마스터입니다.

회고

2주 동안 다섯 번 크게 갈아엎었습니다. 5분 만에 전설 칩이 나와 금방 끝나는 문제는 100층 구조와 8단계 등급으로 고쳤습니다. 기능을 더할수록 기획에서 멀어져, 안 바꿀 핵심을 먼저 정해야 한다고 배웠습니다.

방문자가 아직 적어 단계별 이탈을 판단할 수 없습니다. 공개만으로는 사람이 오지 않았습니다.

다음

결제 상품을 등록해 실제 구매를 시험하고, 유입 경로를 나눠 시험하고, 8단계 기록으로 이탈 구간을 고칩니다.

만든 방식

제품 안의 측정
첫 접속부터 첫 뽑기까지 8단계와 던전 방별 진행, 튜토리얼 건너뛰기를 기록합니다. 저장 데이터 보호(세션 잠금)와 영어 자동 전환(약 370문장)도 넣었습니다.
확인한 것
결제 상품 10종의 지급 흐름과 중복 지급 방지를 테스트 구매로 확인했습니다.
아직 모르는 것
상품 등록 전이라 실제 결제 데이터가 없습니다.
AI를 쓴 곳
화면 설계, 일부 3D 모델
